# PM Panel Studio

**Produktseite:** [pm-networks.com/produkte/panel-studio](https://pm-networks.com/produkte/panel-studio/)

Wandpanel-Oberfläche für Home Assistant: rotierende Hinweiskarten mit Ringtimern, Ruhe- und Wachzustand über
Bewegungsmelder, Kamera-Overlay bei Ereignissen und alle Funktionen des Dashboards als Module. Einzelheiten in der
Dokumentation der App.
