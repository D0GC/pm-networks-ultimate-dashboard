# Satzquellen

- `allgemein.txt`: Auswahl aus der deutschen Satzsammlung von Mozilla Common Voice
  (`server/data/de/sentence-collector.txt`), gemeinfrei (CC0 1.0). Gefiltert auf 6–16 Wörter, nur deutsche
  Schriftzeichen, ohne Ziffern, Abkürzungen und derbe Wörter; ausgewählt auf möglichst breite Abdeckung der
  Lautfolgen.
- `haus.txt`: eigene Hausansagen für PM Panel Studio (Zahlen ausgeschrieben, so wie sie später gesprochen werden).
